# Pinceaux intégrés

Ces pointes proviennent d'un pack de pinceaux Krita (`Brushs.bundle`, exporté de Krita 5.3.3), dont les
réglages et les images de pointes sont ceux livrés avec Krita par ses contributeurs et contributrices
(https://krita.org). Licence déclarée par le pack : **CC-BY-SA** (Creative Commons Attribution –
Partage dans les mêmes conditions).

Elles ont été converties en masques par `tools/krita-brushes.py` (forme, fondu, texture et pinceau de
masquage cuits dans la pointe ; les dynamiques de Krita ne sont pas reprises). Ces fichiers restent sous
CC-BY-SA : toute version modifiée de ces pointes doit être partagée sous la même licence, en citant Krita.
Le code de Lumitype, lui, reste sous licence MIT.
