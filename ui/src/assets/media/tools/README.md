# Animations des outils

Une animation par outil, nommée d'après son identifiant : `move.gif`, `marquee.gif`, `lasso.gif`,
`wand.gif`, `quickSelect.gif`, `crop.gif`, `eyedropper.gif`, `heal.gif`, `brush.gif`, `eraser.gif`,
`fill.gif`, `pen.gif`, `text.gif`, `pathSelect.gif`, `shape.gif`, `hand.gif`, `zoom.gif`.

Format conseillé : **500 × 200**, quelques secondes, en boucle, moins de 1 Mo.

Tant qu'un fichier manque, la bulle affiche `../placeholder.gif`. Rien d'autre à modifier :
déposer le GIF au bon nom suffit.
