# Animations des tutoriels

Une animation par emplacement de tutoriel, nommée d'après le `name` du bloc `gif` de l'article
(voir `ui/src/lib/articles/`). Par exemple `outil-pinceau-dureté.gif`.

Format conseillé : **960 × 540**, quelques secondes, en boucle, moins de 2 Mo.

Tant qu'un fichier manque, l'article affiche `../placeholder.gif`. Rien d'autre à modifier :
déposer le GIF au bon nom suffit.
